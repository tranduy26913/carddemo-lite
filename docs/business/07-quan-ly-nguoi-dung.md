# 07. Quản lý người dùng (Admin)

**Mục đích:** Admin quản lý tài khoản đăng nhập hệ thống.

**Chức năng:** Sửa và xóa người dùng (ID, họ tên, mật khẩu, loại Admin/User); admin nhập User ID để chọn người dùng. Người dùng ban đầu được nạp bằng job DUSRSECJ.

**Quy tắc:** Chỉ Admin truy cập.

**Chương trình:** CU02 / COUSR02C, CU03 / COUSR03C.
