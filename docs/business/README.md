# Nghiệp vụ hệ thống CardDemo

CardDemo là hệ thống quản lý thẻ tín dụng trên mainframe (CICS/COBOL, VSAM) — phiên bản Lite.

**Thực thể chính:** Khách hàng (Customer) – Tài khoản (Account) – Thẻ (Card) – Giao dịch (Transaction), liên kết qua bảng cross-reference (XREF).

**Vai trò:** Admin (A) – quản trị hệ thống; User (U) – nhân viên nghiệp vụ.
